# Sanctum SOF-45 Hooks

A Foundry VTT module for **Cyberpunk RED** that adds useful automation for Solo of Fortune 2045 ammunition and Machine Gun Autofire.

---

## Features

### Ammo Support
- **High Precision Ammo**
  - +1 to hit on single shots
  - +2 to hit on Aimed shots
  - No bonus on Autofire
- **Tracer Ammo**
  - +1 to hit on Autofire
- **Explosive Ammo**
  - –2 to hit (normal / Autofire)
  - –100 to hit on Aimed shots
  - Critical Injury reminder when 2+ dice show 5 or 6
- **Other Ammo Reminders**
  - Burrowing
  - High Velocity
  - Hyper Expansive
  - Hollow Point / Serrated

### Machine Gun Autofire
- Automatically detects Machine Guns (including Midnight Assault HB, Helix, etc.)
- Calculates the correct Autofire DV based on distance
- Posts a clean Diwako-style hit/miss message
